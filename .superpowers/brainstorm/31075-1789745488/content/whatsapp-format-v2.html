C — Boxed Header

Unicode box-border around the shop name for a "printed slip" feel. A bit more visually distinct opening but can render oddly on some phone fonts.

My recommendation: B (Minimal/Airy). Option C's unicode box characters sometimes misalign on iOS vs Android fonts, and A's dotted leaders can wrap awkwardly on narrow screens with long item names. B stays readable everywhere and still looks organized via bold section headers + item counts.
